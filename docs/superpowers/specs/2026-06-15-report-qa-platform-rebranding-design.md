# 智能报表问数平台品牌替换设计

## 目标

将所有用户可见的 `SQLBot` 品牌内容替换为新的平台和助手名称，确保登录、主界面、聊天、嵌入助手、系统设置、关于弹窗、API 文档及安装提示中不再向用户展示 `SQLBot`。

内部代码标识、接口字段、文件路径和现有加密密钥保持不变，避免破坏兼容性和已有加密数据。

## 品牌名称

| 语言 | 平台名称 | 助手名称 |
| --- | --- | --- |
| 简体中文 | 智能报表问数平台 | 智能报表问数助手 |
| 繁体中文 | 智慧報表問數平台 | 智慧報表問數助手 |
| 英文 | Intelligent Report Q&A Platform | Intelligent Report Q&A Assistant |
| 韩文 | 지능형 보고서 데이터 질의 플랫폼 | 지능형 보고서 데이터 질의 도우미 |

## 用户可见内容

### 全局与登录界面

- 主页面和嵌入页面的浏览器标签标题使用对应语言的平台名称。
- 外观配置缺失或许可证无效时，网站名称回退为简体中文平台名称，不再回退为 `SQLBot`。
- 登录页 Logo 旁的平台名称及欢迎语使用对应语言名称。
- 登录后的导航栏和聊天页标题沿用外观配置中的平台名称。

### 聊天与嵌入助手

- 默认聊天欢迎语使用对应语言的助手名称。
- 嵌入式助手标题、欢迎语、预览界面和嵌入设置默认值使用对应语言的助手名称。
- 已由管理员保存到数据库中的自定义外观或助手配置继续优先于代码默认值；本次不自动覆盖管理员已有自定义配置。

### 系统设置与管理界面

- 外观设置、登录页预览、平台预览、认证设置和 API Key 提示中的品牌文字全部替换。
- 问数助手名称的默认值使用简体中文助手名称。
- 用户新增、导入和重置密码界面显示的新默认密码改为 `Report@123456`。

### 关于页面与 API 文档

- 关于弹窗中带有 `SQLBot` 文字的品牌图片替换为相同像素尺寸的纯白图片。
- FastAPI 文档和 MCP 服务中用户可见的标题及描述替换为英文平台名称。
- 服务日志、Python 类名和内部异常类型不属于用户界面，不做品牌重命名。

### 安装与部署提示

- Docker、安装模板和安装脚本中的默认密码改为 `Report@123456`。
- 安装、卸载和服务管理脚本中终端用户可见的产品名称改为简体中文平台名称。
- 环境变量名、容器内部技术标识和兼容性配置键保持不变。

## 图片处理

- 已确认包含 `SQLBot` 可见文字的图片，替换为同尺寸纯白图片。
- 仅包含无文字机器人图标的资源保留，不做替换。
- SVG 中若存在可见的 `SQLBot` 字形路径，则按带品牌文字的图片处理；仅存在于 `<title>` 等无视觉影响的元数据时改为新平台名称。
- 图片替换后保持原文件名、格式和尺寸，避免修改组件引用和布局。

## 明确不修改的内容

- `sqlbot_name`、`getSQLBotName`、`SQLBotLogUtil` 等代码标识。
- `chat.sqlbot_name` 等接口字段、配置键和数据库字段。
- `SQLBot1234567890` 等前后端加密密钥。
- `sqlbot_xpack` 等 Python 包名、导入路径和文件路径。
- 已存在用户的密码、数据库中管理员保存的自定义品牌配置。

## 实施方式

1. 增加自动化品牌扫描测试，规定用户可见文件和资源中不得保留 `SQLBot`。
2. 先运行测试并确认因现有品牌内容而失败。
3. 定向修改四种语言的用户可见文案和默认品牌值。
4. 修改默认密码及部署、安装提示。
5. 生成并替换同尺寸纯白品牌图片。
6. 再次运行品牌扫描、前端测试、后端相关测试和前端生产构建。
7. 对登录、聊天、系统设置、嵌入助手和关于弹窗进行页面检查。

## 验收标准

- 四种语言界面中的平台名和助手名符合本设计表格。
- 用户可访问的页面、提示、图片、API 文档和安装输出中不出现 `SQLBot`。
- 默认密码配置统一为 `Report@123456`。
- 加密密钥、接口字段、内部类名及包路径未被修改。
- 前端生产构建成功，相关自动化测试通过。
- 当前管理员已有密码和已有自定义外观配置不被自动变更。
